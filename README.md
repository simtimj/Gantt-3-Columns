# Gantt 3 Columns (Focus Workspace)

Google Apps Script web app: a three-column daily workspace — **Today / Tasks**, **Notes** and **Reference** — saved to a Google Sheet. Built mostly from a phone; every push to `main` runs `clasp push`. The /dev link uses that pushed code; the workflow does not update a versioned /exec deployment.

Last updated: 2026-11-11

Data organization: [current owners, IDs and a reversible pilot plan](docs/EFFICIENCY_DATA_MAP.md). Operating guide: [efficiency handoff and resume steps](docs/EFFICIENCY_HANDOFF.md).

## ✅ Working

- **📅 Calendar: add / edit / delete events (phase 2)** (confirmed 2026-11-08): in the 📅 Calendar panel, **+ New** (or drag on the grid; on the phone hold, then drag) opens a small form: title, All day, start / end. **Save** puts it on your **main calendar** with reminders off. Tap an event → **Edit** (title, times, all-day on / off; the same event is changed, never copied) or **Delete** (asks first). Save is blocked while saving and a retry can't make a second copy; if a save fails the form stays open with your text and a **Retry save** button. **Repeating events and the Events calendar are read-only** (edit those in Google Calendar). Moving / resizing by drag is phase 3.
- **📅 Calendar panel (phase 1)** (confirmed 2026-11-08): a **📅 Calendar** button in the top header (next to ☾) slides a calendar in from the right (on the phone it leaves a thin strip of the page peeking out on the left; tap the strip to close). It shows your Google Calendar (main + Events calendars) in **Day** / **Week** views with **‹ › Today**, timed and all-day events in their own colors (the same softer colors Julius's Google Calendar app shows, matched from a screenshot: Tomato red, Tangerine orange, Banana yellow, Blueberry blue, Graphite grey…; dark or white text picked for readability; 🧪 2026-11-10), Graphite (done) ones grey and struck through, in Google Calendar's font (Google Sans Flex, medium-weight titles, bigger event text on the phone), always in Pacific time. Tap an event for its time, calendar and an **Open in Google Calendar** link. Loading / no events / error + **Retry** messages, ↻ reloads. **✕ Close**, Esc or tapping outside goes back to the Gantt exactly as it was. Nothing is written to the calendar yet. Later phases (editing, daily planning, timer, review) are planned in `docs/NOTES.md` → "Calendar panel (FullCalendar)".

**Layout**
- Three columns: Today / Tasks, Notes, Reference. Columns are resizable (drag the divider), with **Fit** and **Reset sizes** buttons.
- **Cols** menu: show/hide columns, single-pane focus view, and **Split** (two panes stacked, on desktop or Mobile mode; a repeated pane is a read-only mirror).
- Mobile mode with phone-friendly sizes; toolbars stay clear of the phone camera/notch.
- Save status ("Ready") sits on the same line as the buttons without changing toolbar height.
- **Jump to today**: tap the TODAY / TASKS header text (top-bar Today button removed 2026-10-29).
- **↻ Refresh** reloads the whole app at its /exec URL (picks up new deploys and data).
- No double-tap zoom on buttons, menus or the toolbar. Menus/panels close on outside tap or Escape.

**Options panel** (Options button — was "Scale"; the one place for settings)
- Workspace scale (50–200%).
- Padding left/right and top/bottom as separate sliders (0–300%).
- Text font and size.

**Today / Tasks and Notes**
- One row per day; loads 7 days back and 3 ahead, then more weeks as you scroll (lazy week loading). **Today** button jumps to today.
- Rich text editor: `[]` + Space = checkbox, Tab / Shift+Tab = indent/outdent (subtasks), code blocks with ```.
- Right-click / long-press formatting menu: bold, underline, strike, indent, outdent, checkbox, subtask, horizontal rule.
- Each day saves automatically to the sheet.
- Notes **+ Template** inserts the Reference cell titled "Journal Template" into the selected Notes day.

**Next Steps** (active short-term queue)
- Hold a checkbox (or right-click it) → pick 0 red (Urgent) / 1 yellow (Soon) / 2 blue (Can be later) / none, and optionally a due date. (Urgency reads 0 / 1 / 2 since 2026-11-08.)
- Urgent panel at the top of Reference lists every urgent task from every day, grouped 1/2/3, with its subtasks underneath. Tap a task to jump to it in Today. Panel is collapsible.

**Reference**
- Cells with a title line and body; collapse/expand each, or all at once with the **−/+** in Reference Options (top-bar Ref button removed 2026-11-04).
- **+ Cell**, search box, drag handle to reorder (in Original order).
- Sort: Original order, Title A–Z, Last modified.
- Delete asks to confirm; deleted cells go to the **Archive** (restore any time, children come back with them).
